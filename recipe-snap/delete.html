Recipe Snap 데이터 삭제 안내

제공: 파이낸셜 인디펜던스(Financial-Independence)

Recipe Snap 의 데이터를 지우는 방법입니다.

1. 앱이 설치되어 있다면 (가장 빠른 방법)

  1. 앱을 열고 설정으로 이동합니다.
  2. "전체 데이터 삭제"를 누르고 확인합니다.
  3. 기기의 레시피·장보기·스크린샷이 모두 지워지고, 서버에 남아 있던 AI 추출 작업 기록도 바로 지워집니다. 서버 삭제에 연결하지 못하면 아무것도 지우지 않고 다시 시도하라고 안내하며 기기 데이터도 그대로 둡니다.

2. 앱을 이미 지웠다면

Recipe Snap 은 로그인 없이 쓸 수 있어 이름이나 이메일을 받지 않습니다. 문의 이메일(ihavesookchi@gmail.com)로 요청을 받지만, 앱이 없으면 누구의 데이터인지 알 수 없어 처리하지 못할 수 있습니다. 남은 기록은 아래 기간이 지나면 자동으로 지워집니다.

서버에 남을 수 있는 것언제 사라지나
AI 추출 작업(입력·초안)7일 뒤(보통 하루 안에) 삭제
서버 로그(가명 처리한 식별값, 작업 번호, 길이·상태. 입력 원문 없음)와 서버 요청 로그(요청 IP 주소, 앱 종류(user agent), 요청을 보낸 곳의 주소(referer, 있는 경우), 요청 경로)30일

익명 식별자, 하루 출처 갱신 호출 기록, 월별 사용 횟수는 "전체 데이터 삭제"를 한 뒤에도 위 기간 동안 남습니다. 무료 횟수를 지웠다 다시 받는 악용을 막기 위해서입니다.

앱 기기에 있던 레시피·장보기·스크린샷은 서버에 올라가지 않으므로 앱을 지우면 함께 사라집니다.
